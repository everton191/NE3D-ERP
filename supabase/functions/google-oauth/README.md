# google-oauth

Placeholder for a future Supabase Edge Function or backend route that would handle Google OAuth securely.

Current status: disabled.

Future secrets must live only in backend environment variables:

- `GOOGLE_CLIENT_ID`
- `GOOGLE_CLIENT_SECRET`
- `GOOGLE_REDIRECT_URI`
- `GOOGLE_ENCRYPTION_KEY`

Do not implement OAuth or store real tokens in this placeholder phase.
