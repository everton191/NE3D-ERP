# Atualizações do Simplifica 3D

Esta pasta registra as versões publicadas do sistema. Cada release deve informar a versão exibida, o `versionCode` Android, as mudanças principais e os testes executados.

## Estrutura de publicação

- Código-fonte: repositório `everton191/NE3D-ERP`.
- PWA: publicação de produção na Vercel.
- APK público e manifesto: repositório `everton191/NE3D-ERP.apk`.
- O Android só oferece atualização quando o `versionCode` do manifesto for maior que o instalado e a assinatura do APK for idêntica à chave estável.
