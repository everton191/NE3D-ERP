# Simplifica 3D 1.0.35

Android: `versionCode 63`

## Principais mudanças

- Bootstrap universal que cria uma instância da Assistente por aplicativo.
- Conversa, memória, cache, configuração e armazenamento do modelo separados por `appId`/`modelScope`.
- Contratos próprios de domínios, rotas, entidades, capabilities e adapters para Simplifica 3D, Rural, Tec e Editor da Loja.
- Navegação cruzada entre aplicativos bloqueada pelo manifesto de cada pack.
- Editor da Loja preservado somente leitura, sem capability ou tool de escrita.
- Direcionamento de Home, Pedidos, Estoque, Calculadora e Caixa e launcher arrastável preservados da versão anterior.

## Validação

- Teste simultâneo dos quatro runtimes com armazenamento compartilhado, sem vazamento de conversa, cache ou seleção de modelo.
- Regressões do Assistant Core, componentes, política local, contexto, UX, provider/storage PWA e contrato do Simplifica aprovadas.
- TypeScript e build web aprovados antes do build Android.

## Limites

- Rural, Tec e Editor da Loja estão prontos para receber adapters, mas a conexão aos serviços reais deve ocorrer dentro dos respectivos projetos.
- IA Leve/Avançada e runtime/modelo WebGPU real continuam dependentes de artifacts validados publicados.
