# Simplifica 3D 1.0.38

Data: 2026-08-24
Android: `versionCode 66`

## Correções

- entrada após login direcionada para a Home, sem abrir automaticamente a tela de outros usuários;
- restauração de sessão válida sem bloquear a abertura durante sincronizações remotas;
- desbloqueio local por senha ou biometria após 12 horas;
- assistente simplificado para FunctionGemma, sem seletor ou menu de outros modelos;
- pedidos, estoque e caixa preparados como rascunho para revisão e confirmação do usuário;
- campo de texto do assistente corrigido e botão de envio compactado;
- telemetria filtrada para não registrar estados informativos e falhas transitórias como bugs críticos;
- runtime Android CPU/ARM64 do FunctionGemma preserva `WRITE_EXPOSED = 0`.

## Validação obrigatória da publicação

- testes e builds Web/Android;
- versão e hash do APK no feed público;
- versão servida pela Vercel;
- teste manual de login, biometria e inferência no Zenfone 8.
