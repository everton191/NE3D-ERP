# Simplifica 3D 1.0.32

Publicação: 12/08/2026
Android: `versionCode 60`

## Alterações

- Atalho visível para a IA Fácil na tela principal.
- Chat local aceita perguntas gerais pelo Gemma 4 E2B compartilhado.
- Consultas da IA usam a camada de funções e o contexto de domínio, sem interpretar a tela.
- Download automático do modelo ao carregar o plugin ou ao abrir o chat sem o modelo pronto.
- Aparelhos sem ARM64, com memória insuficiente ou sem espaço para o modelo não iniciam o download e recebem um aviso claro.
- Arquivos da IA passam a fazer parte dos recursos empacotados no Android.

- `npm run android:sync`
- `gradlew testDebugUnitTest assembleDebug`
