# Benchmark E-commerce - Simplifica 3D

Referencias: Shopify e Nuvemshop.

Usar como referencia para:

- vitrine clara;
- produtos com fotos;
- categorias;
- produto indisponivel;
- botao WhatsApp;
- compartilhamento;
- checklist de publicacao;
- pedido/orcamento vindo da loja.

Nao copiar agora:

- checkout completo complexo;
- marketplace proprio;
- automacao de marketing;
- campanhas avancadas.

Regra do Simplifica:

Loja publica deve ser clara, leve, tema claro fixo e isolada do ERP.
