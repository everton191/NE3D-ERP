# Benchmark ERP - Simplifica 3D

Referencias: Odoo, Bling, Tiny, Olist.

Usar como referencia para:

- pedidos;
- estoque;
- caixa/financeiro;
- planos;
- permissoes;
- relatorios;
- superadmin.

Nao copiar agora:

- fiscal completo;
- multiplos depositos complexos;
- marketplace;
- CRM avancado;
- BI pesado.

Prioridade para o Simplifica 3D:

- pedido completo;
- estoque por rolo/material;
- caixa confiavel;
- permissao por plano;
- relatorios basicos;
- logs e auditoria.
